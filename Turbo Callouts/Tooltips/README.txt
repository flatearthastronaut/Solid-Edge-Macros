Place the recording here as Turbo Callouts.wmv (or Turbo Callouts.mp4).
Run ..\Build.cmd. The ZIP in Compiled Executables includes this folder and an
automatically converted MP4 for each WMV. Original recordings stay unchanged.
A supplied same-name MP4 takes precedence. Install the updated ZIP through
Macro Manager and restart Solid Edge. Hammill add-in v0.8 supports discovery.
